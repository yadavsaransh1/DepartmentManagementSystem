```
70-79   C  Average
60-69   D  Below Average
< 60    F  Fail (Need to retake)
```

### Calculating Your GPA (Grade Point Average)

**What is GPA?** A number from 0.0 to 4.0 showing overall performance.

**How it's calculated**:
1. Assign points to each grade:
   - A = 4.0
   - B = 3.0  
   - C = 2.0
   - D = 1.0
   - F = 0.0

2. Multiply grade points by course credits
3. Divide by total credits

**Example**:
```
CS101 (4 credits)  → Grade A = 4.0 × 4 = 16.0
CS201 (3 credits)  → Grade B = 3.0 × 3 = 9.0
CS301 (3 credits)  → Grade C = 2.0 × 3 = 6.0
───────────────────────────────┤
Total = 10 credits             31.0 points
GPA = 31.0 ÷ 10 = 3.1 / 4.0
```

### CGPA (Cumulative GPA)

- GPA = Your grade this semester
- CGPA = Average of all semesters so far
- Universities use CGPA for final degree classification

## <a name="assignments"></a>6. Assignments & Submissions

### Finding Assignments

**Path**: Dashboard → Assignments Tab

Shows all current assignments:

| Course | Title | Due Date | Status | Marks |
|--------|-------|----------|--------|-------|
| CS101 | Chapter 5 Exercises | Mar 30, 10 AM | Submitted | 45/50 |
| CS201 | Sorting Algorithms | Apr 5, 11:59 PM | Pending | — |
| CS301 | Database Design | Apr 8, 5 PM | Not Submitted | 0 |

**Status Types**:
- 🟢 **Submitted**: You turned in the assignment
- 🔴 **Not Submitted**: Deadline passed, no submission
- 🟡 **Pending**: Still time to submit
- 🔵 **Late Submitted**: Submitted after deadline (marks may be reduced)

### Downloading Assignment

**Step 1**: Click on assignment name

**Step 2**: Review assignment details:
- Title & description
- Due date & time
- Maximum marks
- Teacher's instructions
- Attached files

**Step 3**: Click **[Download Files]**
- Problem statement PDF
- Template files (if provided)
- Sample data/test cases

**Step 4**: Complete the assignment
- Follow instructions
- Test your work
- Keep a backup copy

### Submitting Assignment

**Important**: **DO NOT SUBMIT LATE** - marks are reduced!

**Steps**:
1. Click assignment name
2. Click **[Submit Assignment]**
3. Click **[Choose File]**
4. Select your completed file
5. Click **[Upload]**
6. Click **[Confirm Submission]**
7. You'll see: "✓ Submission successful!"

**File Requirements**:
- Formats: PDF, DOC, DOCX, TXT, ZIP, RAR
- Max size: 5 MB
- Avoid Gmail attachments (doesn't work)

### Late Submission

**Can I submit late?** 
- Usually **NO** - deadline is deadline
- If submitted late:
  - Marks reduced (usually -10% per day)
  - May be rejected
  - Must have valid reason

**Exception**: 
- Medical emergency + certificate
- University event + documentation  
- System error (contact teacher)

### Checking Grades on Submissions

Once teacher grades your submission:

1. Go to Assignments tab
2. Click assignment
3. Click **[View Grade]**
4. See:
   - Marks awarded
   - Teacher's feedback comments
   - Time of grading

1. Click **[Forgot Password?]** on login page
2. Enter your email

4. Check email (especially spam folder)
5. Click reset link
6. Create new password
7. Login with new password

- Wait 5 minutes & try again
- Check spam/junk folder
- Ask IT desk to reset (bring student ID)

## <a name="troubleshooting"></a>10. Troubleshooting

### Common Issues

#### Issue 1: "I Can't See My Courses"
**Problem**: Dashboard shows no courses

**Why it happens**:
- Still waiting for course enrollment processing
- Dropped courses aren't shown
- Wrong academic year selected

**Solutions**:
1. Check semester dropdown: Is it current semester?
2. Wait 24-48 hours after registration
3. Logout & login again
4. Contact admin office (they assign courses)

#### Issue 2: "My Attendance Shows 'Absent' but I Was There!"
**Problem**: Marked absent even though you attended

**Why it happens**:
- Teacher made mistake
- You were marked late, system converted to absent
- System synch issue

**Solutions**:
1. **Talk to teacher** politely in person
2. Explain when you attended
3. Ask teacher to correct (they can modify within 30 days)
4. If not fixed, email with date/time & ask for review

#### Issue 3: "I Submitted an Assignment But It Shows 'Not Submitted'"
**Problem**: System says no submission even though you uploaded

**Why it happens**:
- Browser error during upload
- Server issue at that moment
- Wrong file extension

**Solutions**:
1. Wait 5 minutes, reload page
2. File may have uploaded despite error
3. Download & check file size (not 0 bytes)
4. Try submitting again
5. If still broken, email teacher immediately with proof

#### Issue 4: "Grade Shows But It's Wrong"
**Problem**: Mark doesn't match what you expected

**Why it happens**:
- Marking rubrić different than expected
- Partial credit given
- You misread the question
- Teacher made honest mistake

**Solutions**:
1. **Review assignment requirements** carefully - did you do everything?
2. **Read teacher's feedback comments** - they explain why
3. **Ask questions in email**, politely: "I'm confused about part B's marking..."
4. **Attend office hours** to discuss
5. **Request grade review** only if true error

#### Issue 5: I Forgot My Email Password Too
**Problem**: Can't access university email, so can't get password reset

**Solutions**:
1. Go to IT Help Desk in person (Building A, Room 105)
2. Bring student ID
3. IT resets email password
4. Then you can do password reset on system
5. Or IT can reset system password directly

#### Issue 6: "Can't Download Files - Server Error"
**Problem**: Trying to download lecture notes or assignment, but error occurs

**Solutions**:
1. Try different browser (Chrome, Firefox, Edge)
2. Clear browser cache (Ctrl + Shift + Delete)
3. Try downloading again after 5 minutes
4. Use mobile phone instead of laptop
5. Email teacher: "I can't access course files"

#### Issue 7: Assignment File Upload Keeps Failing  
**Problem**: Get error "File upload failed" repeatedly

**Why it happens**:
- File too large (over 5 MB)
- File type not supported  
- Browser compatibility issue
- Internet connection dropped

**Solutions**:
1. **Check file size**: Must be under 5 MB
2. **Check file type**: PDF, DOC, DOCX, TXT work best
3. **Use Chrome browser**: Most compatible
4. **Compress file**: ZIP or RAR if large
5. Try uploading again when network strong
6. As last resort: Email to teacher directly (explain error)
